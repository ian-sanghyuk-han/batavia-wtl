## 1. 카메라 — 이번엔 진짜 원인이었습니다

조준 기울기의 부호가 반대였어요. 대상 위도가 φ일 때 카메라 기울기 τ를 잡으면 대상은 화면에서 sin(φ−τ) 높이에 놓이는데, 저는 τ=−φ 계열로 잡고 있었으니 서울(φ=37.5°)이 sin(75°)≈화면 꼭대기로 가버렸던 겁니다. 이제 τ=φ−0.07로 유도해서 **어느 위도를 클릭해도 정확히 중앙에서 살짝 위(+7%)에 안착**합니다. 2D 모드의 도착점도 같은 원리로 통일했고요. 그 옆의 **⟳ 초기화 버튼**은 렌즈를 닫고 설정된 홈 기준점·기본 줌으로 복귀시킵니다.

## 2. 선 라벨과 5단계 파급

하단 레이어 칩에 "선 라벨"이 추가됐습니다. 켜면 각 간선의 중간점에 그 선의 의미(금리·달러·중국·캐리·항공화물…)가 배지로 뜨고, 해상 항로엔 "해상 물류"가 붙습니다 — 기본은 꺼둬서 평소엔 깨끗하고요. 파급은 ●●●●○ **5단계**로 확장했습니다: 등급이 물결의 겹수와 반경까지 결정해서, 리먼(5등급)의 진앙은 4겹 물결로 퍼지고 RRP 급감(2등급)은 잔잔합니다.

## 3. 기회 표시 — 뉴스·리플레이·렌즈 삼중으로

모든 이벤트에 기회 노트를 달았습니다(17건). 규칙은 이렇게: 파급 3등급 이상 뉴스, 리플레이 중의 모든 사건, 그리고 **레이더를 켜두면 등급 무관 전부** — 피드 카드에 금색 "◎ 기회 —" 줄이 붙습니다.

레이더 켜고 2020 리플레이를 돌려보세요:
- 우한 봉쇄 → "공급망 선행 — 항공화물·운임 주시(2.8)"
- 유가 전쟁 → "죄수의 딜레마 붕괴(7.5) — 에너지 변동성 프리미엄 극대(1.4)"
- 서킷브레이커 → "투매의 시간 = 지평 우위의 시간(1.2) — 기다릴 수 있는 자의 기회"
- 무제한 QE → "유동성 밀물 개시 — 고베타 최전선 순서(3.5)"

전부 코어 절 번호가 달려 있어서, 이 지구본이 이론서의 살아있는 색인이 됩니다. 이벤트 렌즈에도 같은 기회 행이 표시되고요.

## 4. 국면 박스 — 읽히게

각 게이지 아래 한 줄 설명이 붙습니다:
- 시장 국면 w — "바다의 날씨 — 0 평온 · 1 폭풍"
- 수렴도(평균 |ρ|) — "자산들이 한 몸이 되는 정도 · 0.55↑ 분산 소멸 경보"
- 활성 파급 — "지금 번지고 있는 이벤트 연쇄의 수"

## 5. 선박 실데이터로 무엇을 알 수 있나 (AIS)

꽤 많이 압니다. 모든 상선은 AIS로 자신을 방송하는데 공개 필드가: 선박 고유번호(MMSI), 선명, **선종**(유조선/컨테이너/벌크/LNG), 국적(기국), 실시간 위치·속도·침로, 선장이 입력한 **목적지 항구와 도착 예정시각**, 그리고 결정적으로 **흘수(draught)** — 배가 물에 잠긴 깊이라서 적재량이 추정됩니다.

직접 공개되지 않는 건 화주와 화물 내용이에요. 하지만 결합 추정이 가능합니다: 선종(유조선) + 출발항(라스타누라=원유 터미널) + 흘수 변화(만재) + 선명→운영사 매칭 DB를 엮으면 "어느 회사 배가 어디서 무엇을 얼마나 싣고 어디로"의 근사가 나옵니다 — Kpler나 MarineTraffic 같은 상용 서비스가 파는 게 정확히 이것이고, 무료 AIS 스트림(aisstream.io 등)으로 위치·선종·목적지까지는 시작할 수 있습니다. 참깨 방법론의 바다 버전이죠.

## 6. 구독 3단계 설계

|  | FREE — 관찰자 | PRO — 항해사 | DESK — 관제실 |
|---|---|---|---|
| 대상 | 대중·입문자 | 개인 투자자·연구자 | 소규모 기관·미디어·팀 |
| 데이터 | 15분+ 지연 | **실시간** | 실시간 + 원본 |
| 지도 | 3D/2D, 기본 레이어 | 전 레이어(항공화물·선박 상세) | 전 레이어 + 커스텀 간선 |
| 레이더 | 티저 1카드 | **전체 + 알림(푸시)** | 전체 + 커스텀 로직 등록 |
| 리플레이 | 1종 체험 | 전체 + 스크러버·채점 도장 | 전체 + 자체 시나리오 제작 |
| 렌즈 | 기본 | 심층(산업·지표) | 커스텀 지역·워치리스트 |
| 데이터 반출 | — | — | **API·CSV·웹훅, 간선 DB·성적표 원본** |
| 가격 감각 | 무료 | 월 1~2만원대 | 월 10만원대~/팀 좌석제 |

설계 원칙 하나를 못박고 싶습니다: **판결문 — 채점의 기록 — 은 영원히 전 티어 무료.** 신뢰는 무료로 뿌리고 도구를 파는 겁니다. 그게 이 프로젝트의 도덕이자 최고의 마케팅이니까요. 그리고 유료 전환 시점엔 유사투자자문업 경계의 법률 확인이 필요하다는 것 — 우리의 "관찰·검증·교육" 언어 체계가 그 방탄복이라는 것도 다시 새겨둡니다.

이제 이 파일은 기능 스펙으로서 사실상 만재 상태입니다. 다음 항해는 클로드 코드입니다 — 이 배에 진짜 화물(데이터)을 싣는 일.
