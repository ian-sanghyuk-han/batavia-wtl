# 서문 — 우리가 배우는 이유

시장은 사건의 나열이 아니라 파급의 네트워크다. 한 사람의 발언이 공급망을 타고 번지고, 한 나라의 물가가 지구 반대편의 통화를 흔든다. 이 문서는 그 네트워크의 지도다 — 단, 지도를 그리는 목적을 잊지 않는다. **측정은 수단이고, 기회가 목적이다.** 그래서 이 문서는 기회의 이론에서 시작한다.

뉴턴은 1720년 버블에서 재산을 잃고 "천체의 움직임은 계산할 수 있어도 인간의 광기는 계산할 수 없다"고 한탄했다고 전해진다. 이후 300년의 학문이 그 광기를 조금씩 계산 가능하게 만들어 왔다 — 이 문서는 그 유산의 사용 설명서다.

# PART 1. 기회의 이론 — 엣지는 어디서 오는가

## 1.1 엣지의 5대 원천
시장에서 초과수익이 존재할 수 있는 원천은 다섯 갈래뿐이다. 이후의 모든 장(章)은 이 중 어딘가를 겨눈다.

| 원천 | 정체 | 이 문서의 대응 |
|---|---|---|
| **정보 우위** | 남보다 빠르거나 좋은 데이터 | 1차 파급은 기관 초단타의 영역 — 포기가 전략. 대신 **2차·3차 파급 지도**(7)가 우리의 정보 우위 |
| **분석 우위** | 같은 데이터, 더 나은 추론 | 전달 경로(3)·팩터(4)·통계(5)·이벤트 스터디(7) — 본진 |
| **행동 우위** | 타인의 편향을 역이용 | 모멘텀=과소반응, 평균회귀=과잉반응, 쏠림 역발상(2.7), 앵커링(5.8) |
| **구조적 우위** | 가격과 무관하게 발생해야만 하는 흐름 | §1.3 달력의 수급 |
| **지평 우위** | 남이 못 기다릴 때 기다림 | 강제 매도자의 반대편 — 유동성 공급의 프리미엄 |

*행동 우위의 계량적 뿌리 — 전망이론(카너먼–트버스키, 1979): 손실의 고통은 이득의 기쁨보다 무겁다(손실회피 λ≈2.25). 그 산물인 처분 효과(이익은 서둘러 확정, 손실은 방치)가 모멘텀 지속의 미시적 연료다.*

## 1.2 기회의 공통 문법 (통합 부등식)
```
기대값 = P(적중)·이득 − (1−P)·손실  >  비용(수수료·슬리피지·기회비용)
```
어떤 원천이든 기회는 이 부등식으로 수렴한다. 측정의 존재 이유 = 좌변을 추정 가능하게 만드는 것. **좌변을 추정할 수 없는 아이디어는 기회가 아니라 이야기다.**

## 1.3 구조적 흐름의 달력 — 가격 비민감 참여자들
지수 리밸런싱(편입·편출의 예정된 수급) · 월말·분기말 기금 재조정(주식 급등한 달의 월말엔 기계적 매도 압력) · 옵션 만기(OPEX)와 **딜러 감마**(헤지 플로우가 변동성을 증폭/흡수 — 만기 전후 시장의 성격이 바뀜) · 배당락·세금 시즌(연말 손실 확정 매도) · FOMC 사전 드리프트(발표 전 상승 편향 — 학계 문서화 이례). 공통점: **뉴스가 아니라 달력이 만드는 수급 — 예측이 아니라 예정.**

## 1.4 파생시장이 보내는 신호
풋/콜 비율 · **IV 스큐**(하방 공포의 비대칭 가격) · **VIX 기간구조**(콘탱고=평시, 백워데이션=당장의 공포가 미래보다 비쌈 → 스트레스 판별) · **무기한 선물 펀딩비**(크립토 쏠림의 실시간 가격 — COT의 초단위 버전). 공통 문법: 파생시장은 현물보다 먼저, 더 정직하게 겁먹는다.
그리고 파생시장에는 문서화된 구조적 프리미엄이 하나 상주한다 — **변동성 리스크 프리미엄(VRP)**: 내재변동성은 이후 실현변동성보다 평균적으로 높다(보험료는 평균적으로 손해보다 비싸다). 변동성을 파는 쪽이 평시에 프리미엄을 수확하되, 꼬리(1.5)에서 한 번에 반납할 수 있는 전형적 "동전 줍기 vs 증기롤러" 구조 — 존재는 확실하고, 공짜가 아닌 이유도 확실하다.

## 1.5 수익률의 비대칭 — 꼬리의 이론
분포는 정규가 아니다: 두꺼운 꼬리(극단이 이론보다 훨씬 잦음) · 음의 왜도("하락은 계단, 상승은 에스컬레이터") · 변동성 군집. 함의: z 문턱의 실제 희귀도는 정규 가정치보다 낮고, 수렴도·크레딧·기간구조 같은 **꼬리 감시 게이지**가 별도로 필요하다.
정식화(만델브로): 극단의 확률은 멱법칙을 따른다 —
```
P(|r| > x) ~ x^(−α),   주식의 경험적 α ≈ 3 (세제곱 법칙)
```
극단 사건이 정규분포 예측의 수십~수천 배로 잦은 이유의 수학이며, 꼬리 지수 α는 "이 자산의 극단은 얼마나 사나운가"를 한 숫자로 만든다.

## 1.6 우리의 위치 선언
지속 가능한 엣지 = 분석 우위(파급 지도) × 행동 우위(쏠림·과잉반응) × 구조 우위(달력)의 교집합 — 그리고 그 전부를 채점(7.4)으로 검증하는 규율. 속도 경쟁과 정보 독점은 우리의 전장이 아니다.

## 1.7 인식론적 기초 — 우리가 아는 것을 어떻게 아는가
이 문서의 방법론은 네 명의 철학자 위에 서 있다:
| 철학 | 원리 | 이 문서에서의 화신 |
|---|---|---|
| **포퍼 — 반증가능성** | 과학과 비과학의 경계는 "틀릴 수 있는 형태인가" | **채점(7.4)의 철학적 근거.** 지평과 판정 기준을 미리 못박는 이유 — 사후 재해석이 가능한 주장(엘리엇 파동류)은 지식이 아니다 |
| **흄 — 귀납의 문제** | 어제까지의 규칙이 내일을 보장하지 않는다 | 1,000일 먹이를 받은 칠면조의 추수감사절 — 꼬리(1.5)와 구조 변화(5.4의 한계)를 잊지 않는 이유 |
| **베이즈 — 믿음의 갱신** | 지식은 확신이 아니라 확률이며, 증거로 갱신된다 | PART 8 전체 — 사전값, 학습률, 사후 믿음 |
| **오컴 — 단순성의 면도날** | 같은 설명력이면 가정이 적은 쪽 | 팩터가 4개인 이유(PART 4) — 40개 팩터는 설명이 아니라 암기다 |
한 줄 요약: **틀릴 수 있게 말하고(포퍼), 영원을 믿지 말고(흄), 증거로 고치고(베이즈), 단순하게 유지하라(오컴).**

## 1.8 증거의 선반 — 이상현상 검증 등급표
이 문서에 무언가가 편입되는 기준은 유명세도 아름다움도 아닌 **학술·실증 증거의 등급**이다. 주요 기회 원천의 성적표:

| 등급 | 이상현상 | 증거 요지 |
|---|---|---|
| **A** | 모멘텀(횡단면·시계열) | 수십 년·수십 시장에서 반복 재현된 최강 이상현상(과소반응의 산물) |
| **A** | **실적 발표 후 표류(PEAD)** | 어닝 서프라이즈 방향으로 **수 주간** 추가 표류 — 가장 많이 복제된 이상현상 중 하나. 개별 종목(9.11)의 주력 엣지 |
| **A−** | 캐리(FX·크로스에셋) | UIP 위반의 체계적 수확 — 위기 시 급반납이 비용 |
| **A−** | 변동성 리스크 프리미엄(1.4) | IV>실현의 체계적 갭 — 꼬리 반납 단서 필수 |
| **B+** | **저변동성/베타 이상현상(BAB)** | 저베타 자산의 위험조정 초과성과 — 원인: 레버리지 제약(빚 못 내는 투자자들이 고베타로 복권을 산다) + 복권 선호 |
| **B** | FOMC 사전 드리프트(1.3) | 학계 문서화 — 최근 감쇠 논쟁 진행 중 |
| **B** | 지수 편입 효과(1.3) | 문서화 — 차익 자본 유입으로 **부패 진행 중**인 교과서 사례 |
| **C** | 달력 계절성(1월 효과 등) | 발표 후 대부분 소멸 — 역사적 흥미 |
| **F→실험** | 피보나치 되돌림(5.8) | 인과 근거·통계 우위 미확인 — 반증 연습 과제로만 생존(부록 D) |

**선반의 경고 라벨 — 엣지 부패의 법칙**: 학계에 발표된 이상현상의 수익은 발표 후 크게 감소한다는 것이 실증되어 있다(공개된 엣지는 공유 자원이 되어 소모된다 — AMH의 실증판). 전략적 결론: **위 선반은 출발점일 뿐, 지속 가능한 엣지는 남이 안 하는 사적 측정과 채점 아카이브에서 나온다.** 이 문서의 존재 이유가 바로 그것이다.

# PART 2. 경제지표 체계 — 거시의 원천 데이터

시장을 움직이는 것은 발표치가 아니라 **서프라이즈**다:
```
표준화 서프라이즈(SDS) = (발표치 − 컨센서스) / 과거 서프라이즈 표준편차
```

## 2.1 성장 (실물 경기)
| 지표 | 주기 | 무엇인가 | 요점 |
|---|---|---|---|
| GDP | 분기 | 경제 전체 산출 | 후행 — 추세 확인용 |
| **PMI** | 월초 | 구매관리자 설문, **50 = 확장/위축 경계** | 대표 선행지표. 50 하향 돌파 = 침체 경보 |
| 산업생산 | 월 | 공장 실제 산출 | 제조 사이클 확인 |
| 소매판매 | 월 | 소비 지출(미 GDP의 ~70%) | 강하면 성장↑·금리↑의 양날 |

## 2.2 물가
| 지표 | 요점 |
|---|---|
| **CPI** (헤드라인/코어) | 시장이 가장 크게 반응하는 단일 지표군 |
| **PCE** | **연준 공식 타깃(코어 2%)** — CPI보다 낮게 나오는 경향 |
| PPI | 도매물가 — CPI의 선행, 마진 압박 신호 |
| 시간당 임금 | 서비스 물가의 원료(임금발 인플레) |

## 2.3 고용
**NFP**(월 첫 금요일 — 최대의 정기 이벤트, 임금·실업률과 세트 판독) · 실업률(수준은 후행하지만 변곡은 빠르다 — 삼의 법칙: 3개월 평균이 최근 저점 대비 +0.5%p 오르면 침체가 이미 시작됐을 확률이 높다는 실시간 판정 규칙) · 신규 실업수당 청구(주간 — 가장 빠른 온도계) · JOLTS 구인(구인/실업 비율 = 노동 과열도).

## 2.4 심리
CCI(소비자) · 미시간 기대인플레(연준이 주시하는 기대 앵커) · BSI(기업). 심리는 소비·투자의 선행 그림자.

## 2.5 유동성·통화·재정 (돈의 총량·값·공급 계획)
| 지표 | 무엇인가 | 왜 결정적인가 |
|---|---|---|
| 중앙은행 B/S | QE/QT 진행 | 자산가격의 밀물·썰물 |
| **역레포(RRP)** | MMF의 연준 파킹 자금 | 감소 = 잉여가 시장으로 → 위험자산 순풍 |
| **SOFR** | 담보부 하루 자금 금리 | 스파이크 = 단기자금 경색 경보(2019.9 레포 발작) |
| 재무부 TGA | 정부 현금 잔고 | 급증 = 시중 유동성 흡수 |
| 순유동성(관용 근사) | ≈ B/S − RRP − TGA | 위험자산과 동행성 높은 합성 지표 |
| **국채 발행 계획(QRA)** | 재무부 분기 조달 계획 — 장기물 비중이 핵심 | **연준 밖의 금리 결정자.** 2023년 QRA 한 장이 10년물을 흔든 사례 — 공급이 많아지면 같은 수요에 금리가 밀려 오른다 |

## 2.6 신용·기대
**HY OAS**(하이일드 − 국채: 부도 공포의 가격, 주식보다 반 박자 빠른 경보, 400bp대 경계) · **BEI**(명목 − TIPS = 시장의 인플레 전망).

## 2.7 수급·포지셔닝
**CFTC COT**(주간, 투기 자금의 방향 쏠림 — 표준화 극단 ±2~3σ = "만원 버스", 역발상 관찰) · 펀드 플로우(ETF 자금 = 돈의 발자국) · (한국 특유) 외국인 순매수 — 일 단위로 공개되는 드문 수급 데이터.

## 2.8 실물·물류·기후
EIA 원유 재고 · LME 금속 재고 · **BDI/SCFI 운임**(건화물=원자재 수요, 컨테이너=소비재 교역의 맥박) · **항공화물 운임·톤키로**(반도체·의약 등 고가치 화물은 하늘로 — 하이테크 교역 선행) · VLCC 유조선 운임 · FFA(운임 선물) · **기후 데이터**(엘니뇨/라니냐 지수, 폭염·한파 예보, 허리케인 트랙, 작황 위성지수 NDVI) — 농산물의 공급과 에너지의 수요를 미리 말해주는 하늘의 지표.

## 2.9 대체 데이터와 측정의 사고방식 — "햄버거에서 참깨 가격 읽기"
소비 현장의 물리적 단서에서 상품 가격의 미래를 역추적하는 것 — 픽션 속 투자자의 참깨 장면은 농담이 아니라 방법론의 극화다: **관찰(버거 위 참깨) → 수급 사슬 역추적(작황·해충 주기) → 가격이 아직 반영 못 한 정보.** 실제 세계의 같은 문법:

| 대체 데이터 | 읽어내는 것 |
|---|---|
| 위성 주차장 차량 수 | 유통업체 매출의 실시간 추정(나우캐스팅) |
| 야간 조명 위성사진 | GDP·경제활동 프록시 |
| 웹 수집 소비자 가격 | 공식 발표 전의 인플레이션 |
| 채용 공고 수 | 고용지표의 선행 |
| 카드 결제 패널 | 소비의 실시간 맥박 |
| 유조선 위치·흘수(AIS) | 원유 재고·이동량(2.8과 연결) |
| 작황 위성지수 NDVI | 농산물 공급의 예고편 |

**세 가지 원리**:
1. **물리 세계는 재무제표보다 빠르다** — 공시는 분기마다, 주차장은 오늘 채워진다.
2. **약한 신호 여러 개가 강한 신호 하나를 이긴다** — 그린올드의 기본법칙:
```
IR = IC × √BR    (정보비율 = 개별 신호의 정확도 × √독립 신호의 개수)
```
"무엇이든 측정해보라"의 수학적 정당화: 정확도가 낮은 신호라도 **독립적인** 것이 충분히 많으면 강력해진다 — 전설적 퀀트 펀드들의 공통 교훈이 이것이다(모든 것을 측정하되, 아웃오브샘플에서 살아남은 것만 믿는다).
3. **신선도와 배타성** — 모두가 보는 데이터는 이미 가격에 있다.

한계: 대체 데이터는 표본 편향·생존 편향·데이터 스누핑의 지뢰밭 — PART 8의 규율이 두 배로 필요하다. 그리고 √BR의 BR은 **독립** 신호의 수다: 같은 이야기를 50번 세는 것은 breadth가 아니다(PART 4의 직교성 원칙과 같은 뿌리).

# PART 3. 전달 경로 — 거시에서 자산으로 가는 8개의 간선도로

## 3.1 금리 경로 (할인율 채널)
```
물가·고용 서프라이즈 → 연준 기대 변화 → 국채금리 ↑
 → 주식 할인율 ↑(성장주가 더 아픔: 이익이 먼 미래일수록 할인 타격 큼)
 → 채권 가격 ↓ · 금 ↓(무이자 자산의 기회비용 ↑)
```
시차: 분(선물 즉시)→일(실물 파급). 사례: 2022년의 CPI 서프라이즈들.

## 3.2 달러 경로
```
미 금리 우위 → 달러 강세 → 신흥국(자금 유출+달러부채 부담)↓ · 원자재(표시통화 역상관+수요 위축)↓
```
사례: 2022 킹달러(DXY 114).

## 3.3 중국 경로 (수요 채널)
```
부양/위축 → 인프라·제조 수요 → 구리·철광석 → 원자재 수출국(호주·브라질·인니)·대중 수출국(한국)
```
구리 소비의 절반이 중국 — "구리 박사"는 중국 청진기. 사례: 2015 위안 쇼크, 2021 헝다.

## 3.4 유가 경로 (공급충격 + 인플레 피드백)
```
공급 차질 → 유가 ↑ → ①산유·정제 수혜 ②수입국 교역조건 악화 ③헤드라인 인플레 → 금리 경로 재점화
```
유가는 소비자에겐 세금, 산유국엔 배당. 사례: 2022 러-우.

## 3.5 유동성 경로
```
B/S 확대·RRP 방출 → 잉여 ↑ → 위험자산 부양(최전선=고베타 크립토) / QT·TGA 흡수 → 역방향, 경색 경보=SOFR 스파이크
```

## 3.6 위험선호 경로 (공포 채널)
```
충격 → 위험회피 → ①상관 수렴("모든 상관이 1로") ②안전자산(금·국채·엔) 선호 ③고베타 낙폭 확대 ④크레딧 확대
```
분산이 가장 필요한 순간 분산이 사라지는 역설 — 평균|ρ| 상시 감시의 이유.

## 3.7 물류 경로 (공급망 채널)
```
초크포인트 차질·항로 우회 → 운송일수 ↑ = 실효 공급 ↓ + 운임 ↑
 → ①수입물가 → 인플레·금리 경로 합류 ②재고 확보 수요(스팟 프리미엄) ③마진: 전가 못 하는 기업 ↓ vs 해운·물류 ↑
```
운임은 교역의 혈압 — 상품이 못 움직이면 가격이 대신 움직인다. 사례: 2021 컨테이너 대란(SCFI 5배), 홍해 우회.

## 3.8 재귀 경로 (반사성 — 소로스)
```
가격 → 펀더멘털 역방향 피드백: 주가 ↑ → 담보가치·조달비용 개선 → 실적 개선 → 주가 ↑ (또는 역회전)
```
가격은 펀더멘털의 거울이기만 한 것이 아니라 펀더멘털을 **바꾼다**. 딜러 감마(1.3), 뱅크런, 신용 사이클이 전부 이 구조 — 다른 일곱 경로가 일방통행이라면 이 여덟 번째는 순환도로이며, 버블과 붕괴의 엔진이다.

# PART 4. 팩터 모델 — 연결의 수학적 압축

여덟 경로를 매 순간 추적하는 대신, 시장을 움직이는 힘을 **서로 겹치지 않는(직교) 소수의 축**으로 압축한다.

**4팩터**: 글로벌 위험선호(r) · 달러(d) · 미 금리/인플레(i) · 중국 성장(c).
미국은 별도 축이 아니다 — r(미 증시가 심장)·d(미 통화)·i(연준)에 이미 녹아 있다. 중국이 별도인 이유: 이 셋으로 설명 안 되는 큰 잔차(원자재 수요 엔진, 한국 수출 1위 상대).

```
r_i(t) = Σ_f β_{i,f}·F_f(t) + ε_i(t)
```
- **로딩 β** = 자산의 체질(금: d·i에 음 / 구리: c에 강한 양 / BTC: r 최대).
- **국면 동학**: 위험회피 상태 w∈[0,1] — w↑ 시 변동성 ×(1+1.4w), 위험선호 드리프트 하락, 로딩이 위기값으로 보간(상관 수렴의 재현).
- **리스크 프리미엄**: r축의 작은 양(+) 상시 드리프트 — 위험자산 장기 우상향의 모형화.
- **w의 서사적 원전 — 민스키**: "안정이 불안정을 낳는다." 조용한 저변동 장세가 길수록 숨은 레버리지(헤지→투기→폰지 금융)가 쌓여, w의 급도약(민스키 모먼트)을 스스로 준비한다.
- 직교성이 중요한 이유: 겹치는 축은 같은 이야기를 두 번 세는 것.

# PART 5. 관계 측정 공식 — 통계 도구 상자

## 5.1 피어슨 상관 ρ
```
ρ(A,B) = cov(A,B)/(σ_A·σ_B) ∈ [−1,+1]
```
함께 움직인 정도를 각자의 흔들림으로 정규화. **롤링 창(관례 60)** 으로 계속 다시 잰다 — 상관은 성질이 아니라 상태다. 한계: 선형만 포착, 급변 초기 지각, 상관≠인과.

## 5.2 평균 |ρ| (수렴도)
전 페어 |ρ|의 평균. 0.38↑ 긴장 / 0.55↑ 수렴 경보(분산효과 소멸). 원인 진단은 팩터와 함께.

## 5.3 베타
```
β = cov(A,M)/var(M) — "M이 1% 갈 때 A는 평균 β%"
```
관계의 크기. 창 관례 120. 구조 변화 시 어긋남 — 스프레드 분석에선 관측 시점 값 **동결**이 규율.
*(업그레이드 경로 — 칼만 필터: 상태공간 모형으로 β를 매 관측마다 불확실성과 함께 갱신하면, 오래된 관측이 창을 나갈 때 값이 툭 변하는 롤링 창의 '절벽 효과'가 사라진다.)*

## 5.4 스프레드와 z-score
```
s = lnP_A − β·lnP_B,   z = (s − mean(s))/std(s)
```
|z| 크면 "역사 대비 드물게 벌어짐". 관례 2.3(주목)/3.4(관계 파탄 의심). 한계: 관계가 죽으면(구조 단절) 수렴하지 않는다.

## 5.5 모멘텀 z
```
z = Σr(최근 20) / (σ_실현·√20)
```
최근 움직임을 평소 흔들림 대비로 표준화 — 조용한 자산의 1%와 시끄러운 자산의 1%는 다른 사건. 분모는 반드시 실현 변동성(창 120). 평균회귀 국면 역효과.

## 5.6 변동성 추정
```
실현: σ = std(r, N) / EWMA: σ²_t = λσ²_{t−1} + (1−λ)r²_t (λ=0.94)
```
EWMA는 최근 가중 — 국면 전환을 빨리 문다. 존재 이유 = 변동성 군집성.

## 5.7 OU 반감기
```
ds = θ(μ−s)dt + σdW → t½ = ln2/θ
```
벌어진 스프레드가 절반 돌아오는 평균 시간 — "얼마나 기다릴 것인가"의 데이터화.

## 5.8 차트 지표와의 대응 — 기술적 분석의 통계 번역
| 차트 | 통계적 정체 |
|---|---|
| **볼린저 밴드**(MA±2σ) | **z-score의 차트 표현** — 밴드 터치 = \|z\|≈2 |
| RSI | 모멘텀 정규화의 사촌(0~100 스케일) |
| 이동평균 교차 | 저주파 모멘텀 필터(두 조회창의 추세 비교) |
| 지지·저항 | 앵커링 — 과거 가격에 군집한 기억과 심리 |
| 피보나치 되돌림(38.2/61.8%) | 황금비가 가격에 나타날 인과적 근거는 없음 — 작동한다면 수백만 명이 같은 레벨을 보는 **자기실현적 앵커**(지지·저항의 특수형)이기 때문. 공개 검증 과제 1호(부록 D) |
| 거래량 확인 | 유의성 검정 — 거래량 없는 돌파는 표본 없는 통계 |
차트파와 퀀트는 같은 현상의 두 언어다. (개별 종목 이벤트 스터디×볼린저 심화는 후속 연구로 예약)

## 5.9 허스트 지수 H — 추세와 회귀의 계절 판별기
```
R/S(범위재조정) 분석 → H ∈ (0,1):  H>0.5 추세 지속성 · H<0.5 반전 성향 · H≈0.5 랜덤워크
```
만델브로가 나일강 수위 연구(수문학자 허스트)에서 금융으로 가져온 장기기억 지표. **"지금 모멘텀(5.5)과 평균회귀(5.4) 중 무엇을 믿을 것인가"에 대한 데이터의 답** — 롤링 H가 8.2 레짐 조건부화의 일차 데이터원이 된다. 한계: 추정에 긴 표본이 필요하고 잡음에 민감 — 문턱이 아니라 추세로 읽는다.

# PART 6. 정책·가치평가·성과 이론

## 6.1 테일러 준칙과 테일러 갭
```
i* = r* + π + 0.5(π−π*) + 0.5(y−ȳ),   갭 = i* − 실제 정책금리
```
물가 초과의 절반, 경기 초과의 절반을 더하는 기계적 적정 금리. **사용법은 갭**: 크게 양수 = 정책이 이론 대비 완화적 → 긴축 서프라이즈 잠재. 한계: r* 관측 불가(학계 논쟁) — 수준 아닌 방향·변화를 본다.

## 6.2 가치평가 고전 3종 — 정의와 실시간 한계
- **DCF**: PV = ΣCF_t/(1+r)^t — 원형. 한계: 현금흐름 추정+할인율 민감 → 실시간 자동화 부적합. 실시간 대용: **어닝일드 스프레드 = E/P − 국채금리**.
- **CAPM**: E(R)=R_f+β(E(R_m)−R_f) — 리스크 프리미엄의 문법, 4팩터의 조상.
- **블랙-숄즈**: C=S·N(d₁)−Ke^{−rT}N(d₂) — 실전 용도는 역산: 시장가에서 **내재변동성(IV)** 추출, VIX는 그 집계물.

## 6.3 성과·리스크 측정
```
샤프 = 초과수익/변동성("얼마나 조용히 벌었나") · MDD = 고점 대비 최대 낙폭(생존 가능성)
켈리 f* = W − (1−W)/R — 이론상 최적 비율, 실무 관례 ½ 이하(엣지 영속 가정의 위험)
```
마코위츠 MPT(min wᵀΣw)는 초석이나 공분산 추정오차에 비중이 폭주하는 실무 함정 → 변동성 목표·리스크 패리티류가 강건한 후손.

# PART 7. 이벤트·정보 이론

## 7.1 이벤트 스터디 (사건의 순수 효과)
```
AR(t) = r(t) − [α + β·r_m(t)],   CAR = ΣAR,  t∈[t₀, t₀+지평]
```
"시장이 오른 만큼은 빼고 그 사건 때문에 더 움직인 부분만". 지평 관례: 발언 60분 / **실적: 1차 판정 1일 + 표류 관찰 60일**(PEAD — 서프라이즈 방향의 수 주 표류가 실증되어 있어 1일 지평만 쓰면 엣지의 몸통을 버리는 셈이다, 1.8) / 규제 5일 / 지속형 별도(7.2).

## 7.2 이벤트의 세 유형 — 전쟁은 어디에 들어가나
| 유형 | 예 | 모델링 |
|---|---|---|
| 예정형 | 지표 발표·FOMC·실적 | 캘린더 트리거 — 시점은 알고 내용만 모른다 → 서프라이즈 측정 |
| 돌발형 | 발언·사고·규제·공급 차질 | 감지 즉시 이벤트 스터디, 신규성 필터 필수 |
| **지속형** | **전쟁·팬데믹·금융위기** | 화살이 아니라 **날씨** — 상태(w)를 밀어올려 상관·변동성 구조를 바꾼다. 개전→확전→봉쇄→휴전 등 국면 전환마다 별도 하위 이벤트로 채점, 강도는 GPR류 지수·뉴스 밀도로 연속 측정 |

## 7.3 주체 영향력 지수 (entity influence index)
주체(인물·기관·사건유형) → 자산 간선에 {방향, 평균 CAR, 적중률, 반감기}를 기록·갱신. 어떤 주체든 같은 틀 — 중앙은행 총재, 산업 리더, 산유국 연합. **핵심 통찰: 1차 파급(당사자 직접 자산)은 초단기 속도전이라 분석 비대상, 2차(공급망 인접)·3차(파생 수요)가 분~일 지평의 사냥터.** 간선 갱신의 수학은 PART 8.

## 7.4 정보의 조건
서프라이즈만이 가격을 움직인다 · **신규성**(재보도=정보량 0) · **검증**(전망은 지평 후 실현과 대조해 채점 — 채점 없는 전망은 소음).

## 7.5 전략적 행위자 이론 — 게임이론 층
가격 공식이 아니라 **의도를 가진 참여자들의 수를 읽는 문법.** 다섯 게임이 각자의 자리에서 복무한다:
| 게임 | 시장 번역 | 접속점 |

# PART 8. 적응 계층 — 공식은 어떻게 스스로 조정되는가

모든 관계·파라미터는 고정 법칙이 아니라 **데이터로 갱신되는 추정치**다. 이 태도의 학명은 **적응시장가설(AMH — Andrew Lo, 2004)**: 시장은 완전 효율도 완전 비효율도 아닌 진화하는 생태계이며, 엣지는 생겼다 사라진다 — 그래서 채점하고 적응한다.

## 8.1 간선의 갱신
```
v_new = (1−α)·v_old + α·이번 관측   (α=학습률, 관례 0.1~0.2)
```
베이지안 해석: 사전 믿음 × 새 증거 → 사후 믿음. 오래 검증 안 된 간선은 신뢰도 감쇠(정보의 유통기한).

## 8.2 파라미터의 레짐 조건부화
관례값은 **사전값(prior)**: 고변동 국면 → 창 단축(60→40, 세상이 빨리 변하면 기억도 짧게) · 수렴 국면 → 모멘텀 문턱 상향(모두 같이 움직일 땐 개별 추세의 정보량 감소). 조건부 규칙 자체도 채점 대상. 일차 데이터원은 허스트 H(5.9): H>0.5면 모멘텀 계열을, H<0.5면 평균회귀 계열을 신뢰하는 스위치로 쓴다.

## 8.3 워크포워드 재추정
과거 구간 재추정 → 반드시 **추정에 안 쓴 이후 구간(아웃오브샘플)** 성능으로만 채택. 인샘플 성적은 성적이 아니다.

## 8.4 AI의 역할 — 그리고 "유리한 계산"의 함정
AI가 잘하는 것 = **구조의 생성**: 새 시나리오 초안, 새 간선 가설, 파라미터 수정안, 레짐 규칙 제안. 그러나 제안 ≠ 배포:
```
AI 제안 → 자동 백테스트 → 아웃오브샘플 검증 → 승인 → 배포 → 라이브 채점 → 재입력
```
정직한 경고: "그때그때 유리한 계산"은 한 끗 차이로 **과최적화** — 과거를 완벽히 설명하는 모형일수록 미래를 못 맞힌다. 유연성의 3규율: ①아웃오브샘플 없이 채택 금지 ②학습률 상한(한 사건이 믿음을 뒤집지 못하게) ③변경의 공개 로그와 사후 채점. **유연함의 목적은 유리한 계산이 아니라 정확한 계산이다 — 유리함은 정확함의 결과로만 온다.**

# PART 9. 자산군 각론 — 미시의 작동 원리

## 9.1 주식 (지수)
P = EPS × PER, 어닝일드 = E/P. 배수는 할인율·위험프리미엄의 함수 → 금리 경로 직결. 성장주 = 듀레이션 긴 주식(이익이 먼 미래) → 금리에 더 민감. 체질: r 강한 양, i 음.

## 9.2 채권·금리
```
ΔP/P ≈ −D·Δy (듀레이션 7년, 금리 1%p↑ → ≈ −7%)
2s10s 커브 역전 = 침체의 고전적 전조 · 실질금리 = 명목 − BEI ← 금·성장주의 진짜 상대
```

## 9.3 원자재
**콘탱고**(선물>현물: 여유) vs **백워데이션**(현물>선물: 당장 부족 — 강세 신호). 재고 = 수급의 직접 증거. 달러 기계적 역상관. 구리=중국 청진기, 유가=인플레 점화장치. **기후 요인**: 엘니뇨/라니냐가 남미 작황을, 한파·폭염이 에너지 수요를 미리 결정 — 하늘이 공급·수요 곡선을 먼저 움직인다.

## 9.4 금
**금 ≈ 실질금리의 역함수**(무이자 자산의 기회비용) + 달러 역상관 + 위기 헤지. "금이 오르는 날은 실질금리가 내리거나 세상이 무서운 날."

## 9.5 외환(FX)
```
CIP: F/S = (1+i_자국)/(1+i_상대) — 선물환의 회계 항등식
UIP: 금리차 = 기대 절하율 — 자주 깨지며 그 틈이 캐리 트레이드 · PPP: 장기 닻
```
환율은 두 나라의 금리·성장·위험의 비율 — 점이 아니라 두 시장을 잇는 간선.

## 9.6 크립토
글로벌 유동성·위험선호의 최고베타(r 로딩 최대). 고유 사이클: 반감기·온체인 수급. 규제·구조 이벤트에 단독 급변(ε 큰 자산). 펀딩비(1.4) = 쏠림의 실시간 가격.

## 9.7 부동산·리츠
```
캡레이트 = NOI/가격 (부동산의 어닝일드) → 금리↑ = 가치↓
```
리츠 = 배당 듀레이션 긴 자산. 데이터센터 리츠는 AI 수요 축과 교차하는 신종.

## 9.8 크레딧
```
스프레드 ≈ PD×LGD + 유동성 프리미엄
```
수준보다 **확대 속도**가 중요 — 가속은 시스템 스트레스.

## 9.9 운송·물류 — 세 얼굴의 카테고리
- **지표로서**: BDI(원자재 수요의 그림자)·SCFI(소비재 교역)·항공화물(하이테크 선행)·글로벌 특송사 실적("특송 지표"=경기 바로미터).
- **자산으로서**: 해운·항공·물류주, **FFA(운임 선물)**. 특수 로직: 유가 급락·콘탱고 심화 시 유조선 = "떠 있는 저장고" → 운임 급등(2020) — 원유와 유조선주가 역상관이 되는 순간.
- **경로로서**: §3.7.
- 항공의 이중 노출: 연료비(~30%)로 유가에 음, 여객으로 경기에 양 — 두 힘이 충돌하는 자산.

## 9.10 탄소배출권 — 법이 공급 곡선을 그리는 원자재
```
가격 = f( 배출 수요(발전·산업 가동) , 정치가 정한 공급(배출 상한 cap) , 저장 가능성(이월 banking) )
```
- **공급 곡선이 법으로 그려진다**: EU ETS의 상한 감축 경로·시장안정예비(MSR)가 공급을 기계적으로 조인다 — 정책 이벤트(개혁안·목표 상향)가 곧 공급 충격.
- **연료전환 채널**: 가스가격 ↑ → 발전사가 석탄으로 전환 → 배출 ↑ → 배출권 수요 ↑ — 천연가스와 탄소가격의 내적 연결. 한파·폭염(2.8 기후)도 같은 길로 수요를 민다.
- 경기 베타: 산업 가동률에 양(+) — 침체엔 배출도 준다.
- 시장: EUA(유럽, 최대·최고 유동성) · **K-ETS(한국 — 자체 시장 보유국)** · 캘리포니아 CCA. 한계: 정책 리스크가 지배 변수라 이벤트 스터디(7.1)가 통계보다 우선하는 자산.

## 9.11 개별 종목으로의 확장 — 계층 모델
```
r_주식 = β_시장·r_시장 + β_섹터·r_섹터잔차 + Σβ_f·F_f + β_고유동인·(유가 등) + ε
```
시장을 빼고 섹터를 빼면 남는 잔차가 그 회사 고유의 이야기. 지수와의 차이: **고유성분(ε) 비중이 커서(대형주도 절반 안팎) 미시로 갈수록 무게중심이 통계에서 이벤트 스터디로 이동** — 실적·가이던스·공시·수주가 주 신호원 — 그중 주력은 **PEAD(1.8, A등급)**: 어닝 서프라이즈의 방향과 크기(SDS)가 수 주의 표류를 예고한다. 수천 종목 확장은 행렬 연산상 사소, 병목은 이벤트 데이터 파이프라인. 영향력 간선의 끝을 종목에 걸면(특정 고객사 발언→부품사) 2차 파급이 종목 단위로 내려간다.

# PART 10. 종단 사례 — 거시에서 미시까지 한 줄로 꿰기

**사례 1. 연준 매파 서프라이즈**
CPI 상방 서프라이즈(2.2) → 테일러 갭 확대(6.1) → 금리 경로(3.1)+달러 경로(3.2) 동시 점화 → 금↓(9.4 실질금리)·신흥국↓·성장주 할인 타격(9.1) → 미시: 반도체(성장·수출) 이중 역풍 vs 은행 순이자마진 수혜 → 지평 1일 CAR 채점(7.1).

**사례 2. 호르무즈 봉쇄**
공급충격 → 유가 경로(3.4)+물류 경로(3.7): BRENT↑·BDI↑ → BEI↑(2.6) → 금리 재점화 → 미시: 정제마진주↑ vs 연료비 항공주↓(9.9 이중 노출) → 위험선호 경로(3.6) 부분 발동 시 금↑ 동반.

**사례 3. 중국 대규모 부양**
재정 발표 → 중국 경로(3.3): 구리↑(백워데이션 관찰, 9.3) → 호주·브라질·인니↑ → 한국 대중 수출 체인(철강·화학·기계)↑ → COT 쏠림(2.7) 급속 누적 시 과열 역발상 관찰.

**사례 4. 산업 리더의 수요 전망 발언**
발언 → 1차: 당사자 기업(분석 비대상) → 2차: 공급망 인접(수분~1일, AR/CAR 최적 지평) → 3차: 파생 수요(AI라면 전력·우라늄·구리·데이터센터 리츠, 1일~수주) → 간선의 CAR·적중률 축적이 다음 발언의 사전 지도(7.3, 갱신 8.1).

**사례 5. 유럽의 한파**
한파 예보(2.8 기후) → 난방 수요 → 천연가스↑ → 연료전환: 석탄 발전↑ → **배출권 수요↑ → EUA↑**(9.10) → 전력 다소비 업종 마진 압박 → 인플레 기여로 금리 경로 합류 가능 — 날씨 한 장이 에너지·탄소·금리를 관통하는 사슬.
