# 서문 — 우리가 만드는 것

젠슨 황이 마이크 앞에서 한 문장을 말하면, 그 파동은 엔비디아를 지나 SK하이닉스로, TSMC로, 그리고 데이터센터가 삼킬 전기와 우라늄으로 번진다. 연준 의장이 단어 하나를 바꾸면 달러가 움직이고, 달러가 움직이면 뭄바이와 상파울루의 아침이 달라진다. 시장은 사건의 나열이 아니라 **파급의 네트워크**다.

그러나 오늘의 도구들은 이 네트워크를 보여주지 않는다. 블룸버그는 데이터를 쏟아내지만 관계를 그리지 않고, 뉴스는 전망을 외치지만 채점받지 않는다. World Trading Live(WTL)는 그 빈자리에 선다: **세계 시장의 관계와 의미를 실시간 지도 위에 그리고, 모든 전망에 성적표를 붙이는 이론 검증 플랫폼.** FOMC 전날 밤의 트레이더가 "매파 시나리오"를 40개의 경로로 미리 돌려보고, 자신의 판단을 스스로 내리게 하는 도구.

우리는 결론을 팔지 않는다. **논리와 분포와 성적표**를 판다.

# PART 1. 제품

## 1.1 정의와 세 가지 약속
**정의**: 전 세계 시장의 가격·자본·자원의 이동과 그 관계·의미를 실시간으로 보여주는 정보·분석·교육 구독 서비스.
1. **지금 무엇이 움직이는가** — 라이브 지도, 항해하는 선박, 이벤트 파문.
2. **어떻게 얽혀 있는가** — 상관 네트워크, 팩터, 항로, (향후) 영향력 그래프.
3. **무슨 뜻인가** — 로직 게이지, 긍/부/중 신호, 시나리오 분포, 공개 적중률.

## 1.2 철학 3원칙
1. **모든 숫자에 논리가 붙는다** — 화면의 어떤 값이든 ⓘ 한 번으로 정의·산식·사용법·한계에 닿는다.
2. **모든 전망은 채점된다** — 발동된 시나리오의 전망은 지평 경과 후 자동 판정, 적중률 상시 공개. 채점 없는 전망은 소음이다.
3. **모든 로직은 켜고 끌 수 있다** — Live Logic 토글. 사용자는 자기 관점에 필요한 로직만 남긴다.

## 1.3 절대 경계 (위반 = 빌드 실패)
- **매매·계좌 기능 0**: 주문·체결·손익·수익률곡선·잔고·입출금·자동매매 — 코드·화면·문구 전면 금지. 자산운용·일임·자문으로 오해될 요소의 원천 차단이 목적이다.
- **신호 언어 규칙**: 매수/매도/사라/팔라 금지. 오직 긍정(▲)/중립(―)/부정(▼) + 근거 로직 + 면책.
- **금지어 기계 검사 목록**: 매수·매도·체결·손익·오토파일럿·원장·거래 일지·주문·포트폴리오·잔고·계좌. **면책 예외 규칙**: 부재를 선언하는 면책 문구("계좌 연동·거래 기능이 없고…")에 한해 '계좌' 1회 허용 — QA가 정확히 1회·해당 문장 내 존재를 검사한다.
- 시뮬 구동 중 SIM 배지·압축비 HUD 제거 금지. 모든 페이지 하단 면책 푸터 고정.

## 1.4 사용 서사
- **FOMC 전야**: 트레이더가 시나리오 랩에서 '연준 매파'를 선택 → 플레이북과 40경로 분포(중앙값·상승확률)를 확인 → 자기 판단의 재료로 삼는다.
- **아침 브리핑**: 애널리스트가 로직 그리드를 훑는다 — 테일러 갭 +0.8%p(긴축 압력 잠재), 크레딧 420bp(경계), 수렴도 0.57(분산 소멸 경보). 3분 만에 오늘의 국면이 잡힌다.
- **학습자**: 대학생이 라이브러리에서 "왜 달러가 오르면 신흥국이 아픈가"를 산식과 함께 읽고, 지도에서 실시간으로 그 일이 벌어지는 것을 본다.

# PART 2. 화면 설계 (UX 정본)

## 2.1 구조 — 단일 스크롤 대시보드
탭 분할은 정보를 숨긴다. WTL은 **한 페이지 세로 스크롤**로 모든 것이 이어지고, 상단 고정(sticky) 내비게이션은 앵커 점프만 담당한다.
```
[헤더: 브랜드 · SIM/시계/실경과 · 압축비 HUD · 속도/테마/일시정지]
[고정 내비: 라이브 지도 | 로직 그리드 | 시나리오 랩 | 로직 라이브러리 | ⚙ Live Logic]
① 라이브 지도  (히어로 — 지도 + 시장 신호 + 뉴스와이어)
② 로직 그리드  (게이지 카드 12+)
③ 시나리오 랩  (플레이북 + MC + 라이브 검증 기록)
④ 로직 라이브러리 (해설 카드 11+)
[면책 푸터]
```

## 2.2 라이브 지도 — 상세 명세
**투영**: 등장방형(뷰박스 1080×470), 육지 = Natural Earth 50m → 2° 래스터 3,640 도트, 30°/20° 위경도 눈금.

**구성요소와 기호 사전** (지도 좌하단 [? 지도 읽는 법] 패널로 상시 제공):
| 기호 | 의미 |
|------|------|
| ● 원 | 시장 노드 16종. 파란 링 = 현재 기준(베이스) 시장 |
| ◠ 곡선 | 기준 시장과의 60분 롤링 상관 — 빨강 동행/파랑 역행, 굵기 = 강도, 흐름 속도 = 강도 |
| ▲▼ 배지 | 이벤트 전망(긍정/부정), 투명도 = 신뢰도 |
| ◆ 다이아몬드 | 초크포인트 7 (호르무즈·수에즈·말라카·파나마·바브엘만데브·보스포루스·지브롤터) |
| ┄ 점선 | 주요 무역 항로 6로 (걸프→아시아, 걸프→유럽, 아시아→유럽, 대서양, 파나마, 희망봉 우회) |
| ➤ 삼각형 | **항해 중인 선박** — 항로당 2~3척, 개별 속도로 상시 운항(시뮬) |
| ◎ 확산 원 | 이벤트 파문 — 진앙에서 2겹 링 확산 + 영향 노드 순차 점화 |

**선박 규격**: 총 16척. 경로 진행도(0~1)를 매 틱 전진, `getPointAtLength`로 위치·방위 산출. **봉쇄 시**: 호르무즈 경유선은 정지+적색 점멸, 희망봉 우회선 3척(금색)이 나타나 고속 운항. 실데이터 단계에서 AIS 스트림으로 대체된다(§6).

**이벤트 연출**: 시나리오 발동 → ① 진앙 좌표(유가=호르무즈, 연준=시카고, 중국=상하이, 위험회피=범지구)에서 금색 파문 2겹 ② 영향 자산 노드들이 160ms 간격 순차 링 점화(방향색) ③ 지도 테두리 금색 발광 ④ 상단 이벤트 배너(제목 + "지평 종료까지 n분"). 배너는 모든 시나리오에 일반화.

**전체화면 모드**: [⛶] 버튼 → Fullscreen API(미지원 시 고정 오버레이 폴백), Esc 복귀, 진입/이탈 시 캔버스 리사이즈.

**베이스 관점**: 셀렉트(10개 시장) 또는 노드 클릭으로 변경 → 상관망·랭킹이 그 시장 중심으로 재편.

**시각 로드맵**: v1(현재) SVG 선박·파문 → L7 클로드 디자인·코드에서 WebGL 파티클 선박 군집·글로우·시네마틱 카메라 → 그 다음 3D 시맨틱 줌(L0 우주~L4 종목, Shift+스크롤 = 정보의 고도).

## 3.2 로직 카드 11종 (파라미터 포함 전문)
1. **상관 네트워크** — ρ = cov(A,B)/(σAσB), 창 60틱 롤링. 관계는 상태다: 국면 따라 변하므로 계속 다시 잰다. 한계: 창 기반이라 급변 초기는 지각.
2. **상관 수렴도** — 전 페어 |ρ| 평균. 문턱 0.38(긴장)/0.55(수렴 경보 — "위기 때 상관은 1로 간다"). 원인 진단은 팩터와 함께.
3. **베타** — β = cov(A,M)/var(M), 창 120. 관계의 크기. 구조 변화 시 어긋남.
4. **모멘텀 z** — z = Σr(20) / (σ실현·√20), σ실현 창 120, 문턱 |z|≥2.3. 실현 변동성 분모가 규율(이론값 사용 금지 — 과거 결함 사례). 평균회귀 국면 역효과.
5. **이벤트 전망·검증** — 전망(자산·방향·신뢰) 기록 → 지평 후 실현 대조(+0.1% 초과 = 적중) → 건별/시나리오별/전체 집계 공개. SIM 적중률은 논리 일관성의 증명이지 시장 예측력의 증명이 아니다(문구 상시 노출).
6. **이벤트 스터디 AR/CAR** — AR = r − (α+βr_m), CAR = ΣAR. 사건의 순수 효과 측정. 영향력 그래프(향후)의 수학적 기초. 지평: 발언 60분/실적 1일/규제 5일/전쟁 지속형.
7. **테일러 갭** — i* = r* + π + 0.5(π−π*) + 0.5(산출갭); **갭 = i* − 실제 정책금리**. 예측기가 아니라 긴축/완화 압력 게이지(+0.4%p↑ 긴축 서프라이즈 잠재). r* 관측 불가 논쟁 → 수준 아닌 방향·변화를 본다.
8. **유동성 지수** — 연준 B/S + RRP + SOFR 합성(시뮬은 합성 AR). 2019 레포 발작·2023 SVB의 선행 계열. 위축 국면의 악재는 두 배로 아프다.
9. **포지셔닝 쏠림** — CFTC 투기 순포지셔닝 표준화(시뮬은 모멘텀 프록시). 극단 ±3σ = "만원 버스", 역발상 관찰 대상. 주간 발표 후행성.
10. **크레딧 스프레드** — HY − 국채. 채권시장의 부도 공포 가격, 주식보다 반 박자 빠른 경보. 400bp대 경계. 수준보다 변화 속도.
11. **항로·초크포인트** — 7관문+6항로+선박. 공급망 충격의 시각 언어. AIS 실데이터 예정.

## 3.3 시나리오 플레이북 6종 (전문)

# PART 4. AI 에이전트 & API

## 4.1 시나리오 자동 진화 루프 (실데이터 단계)
```
뉴스 스트림(GDELT·RSS·공시) → [에이전트] 신규 시나리오 초안 / 기존 파라미터(방향·신뢰·지평) 수정안
 → [자동 백테스트] 과거 유사 사건 재생 — 개선 없으면 폐기
 → [사람 승인 게이트] 변경 요지·근거 제시
 → 배포(버전·변경 로그 공개) → 라이브 채점 결과가 다시 에이전트 입력으로
```
안전장치: ① 에이전트는 제안만, 배포 권한 없음 ② 모든 변경 공개 로그 ③ 적중률 하락 시 롤백 후보 자동 표시 ④ 신규성 필터(재보도 영향 0, 임베딩 중복 제거).

## 4.2 API 설계 초안 (후속 상품)
| 엔드포인트 | 반환 |
|---|---|
| `GET /v1/gauges` | 전 로직 게이지 현재값+상태 판정 |
| `GET /v1/scenarios` | 플레이북 목록(버전 포함) |
| `POST /v1/simulate {scenario,K}` | MC 분포 {p10,med,p90,pUp} per asset |
| `GET /v1/verification` | 적중률 이력(기간·시나리오별) |
예시: `/v1/simulate {"scenario":"FED_HAWK"} → {"US10Y":{"med":+0.9,"pUp":0.88},...}`
전 응답은 **파생 데이터**(원시세 역산 불가)로 설계 — 거래소 라이선스 최경량 경로(§6). 유료화 전 법무 검토 필수. 버전 정책: /v1 고정, 파괴적 변경은 /v2.
