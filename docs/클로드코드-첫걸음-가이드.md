# 클로드 코드 첫걸음 가이드 — 개발자가 아닌 선장을 위하여
> Batavia Project · 2026-07-26 · 어려운 말 없이, 순서대로 따라 하면 되는 문서

---

## 1. 클로드 코드가 뭐냐면

지금까지 저(채팅의 클로드)는 **설계사무소**였습니다 — 도면(HTML 목업, 이론서, 스펙)을 그렸죠. 클로드 코드는 **현장의 시공팀**입니다. 당신 컴퓨터 안에 상주하면서 파일을 직접 만들고, 고치고, 인터넷에 배포하고, 데이터 배관을 까는 동료예요. 대화하는 방식은 지금 저와 똑같습니다 — 한국어로 말하면 됩니다.

**"수정 요청하면 잘 들어주나?"** — 네, 그게 클로드 코드의 존재 이유입니다. "레이더 글씨가 작아, 키워줘", "이 색 마음에 안 들어", "어제 만든 거 되돌려줘" 같은 자연어면 충분해요. 당신은 이미 이 방식으로 채팅에서 지구본 하나를 통째로 만들어낸 사람입니다. 똑같이 하시면 됩니다.

## 2. 준비물 체크리스트 (오늘 할 일)

1. **클로드 데스크톱 앱** 설치 → 왼쪽의 **Code 탭**이 클로드 코드입니다. (터미널 검은 화면 안 봐도 됩니다)
2. **GitHub 계정** 만들기 (github.com — 무료, 이메일만 있으면 됨). GitHub는 비유하자면 **작업실+금고+전시장**입니다: 코드를 보관하고(금고), 버전을 기억하고(작업실), GitHub Pages라는 기능으로 세상에 공개합니다(전시장 — 아이폰에서 안 보이던 문제가 이걸로 해결됩니다).
3. **FRED API 키** 발급 (5분): ① fred.stlouisfed.org 접속 → ② 우상단 My Account 가입 → ③ API Keys 메뉴 → ④ Request Key → ⑤ 나온 문자열 복사해서 메모장에 보관. 이게 첫 번째 열쇠입니다.

**API 키란?** 도서관 회원증입니다. 데이터 도서관(연준, 선박 관제소…)이 "누가 빌려가는지"만 알려고 주는 무료 회원증이에요. 주의사항은 딱 하나 — **회원증을 남에게 보여주지 않는다.** 클로드 코드에게 건네는 건 안전하지만(금고에 넣는 법을 알아요), 인터넷 게시판이나 공개 파일에 붙여넣으면 안 됩니다. 클로드 코드가 "Secrets에 저장할게요"라고 하면 그게 금고에 넣었다는 뜻입니다.

## 3. 첫 세션 — 이대로 복사해서 붙여넣으세요

클로드 코드를 열고, 프로젝트 폴더(다운로드해둔 우리 파일들이 있는 곳)를 지정한 뒤:

> **첫 번째 메시지:**
> "이 폴더의 `BATAVIA-CLAUDE-CODE-HANDOFF.md`를 정독해줘. 이 문서가 우리 프로젝트의 단일 진실 원천이야. 다 읽었으면 ① 네가 이해한 프로젝트 요약 다섯 줄 ② P0 단계에서 할 일 목록 ③ 나에게 지금 필요한 것(계정·키)을 쉬운 한국어로 알려줘. 나는 개발자가 아니니까 모든 보고는 비유를 섞어서 해줘."

그러면 클로드 코드가 GitHub 계정과 FRED 키를 요청할 겁니다(§2에서 이미 준비했으니 바로 진행됩니다). 이어서:

> **두 번째 메시지:**
> "좋아, P0을 시작하자. GitHub 저장소를 만들고 정본 파일들을 이식한 다음 GitHub Pages로 배포해줘. 끝나면 내가 아이폰 사파리에서 열어볼 주소를 줘."

30분~1시간 안에 `https://당신아이디.github.io/batavia` 같은 주소가 생기고, 아이폰에서 지구본이 돌아갑니다. **이게 P0 완료의 확인 방법입니다** — 코드를 볼 필요 없이, 화면으로 검수하세요.

## 4. 그다음 세션들 — 말하는 법 예시

- P1: "핸드오프 문서의 P1을 진행해줘. 특히 진짜 해안선(TopoJSON)이랑 아이폰 터치 조작부터."
- 수정: "리플레이 스크러버 만들어줬네. 그런데 드래그가 뻑뻑해. 부드럽게 해줘." (스크린샷 첨부하면 더 좋음)
- 에러: 콘솔에 빨간 글씨가 보이면 → 전체 복사 → "이 에러 떴어" + 붙여넣기. 이번에 저한테 하신 그대로요 — 그거면 완벽한 버그 리포트입니다.
- 되돌리기: "방금 변경 마음에 안 들어. 이전 버전으로 되돌려줘." (깃이 전부 기억하고 있어서 언제든 가능)
- 확인 요청: "지금까지 한 거 배포해서 주소 줘. 폰으로 볼게."

**좋은 요청의 3요소**: 무엇이(대상) + 어떤 점이(문제/바람) + 가능하면 화면 증거. 기술 용어는 몰라도 됩니다.

## 5. 돈 이야기 — 뭐가 무료고 뭐가 유료인가

| 항목 | 비용 |
|---|---|
| GitHub + Pages 호스팅 | 무료 |
| FRED·GDELT·aisstream·Open-Meteo 등 P0~P2 데이터 | 전부 무료 티어 |
| 클로드 코드 사용 | 구독 요금제 내 사용량 |
| 커스텀 도메인 (예: batavia.io) | 선택 — 연 1~3만원대 |
| 회원 DB(Supabase) | 무료 티어로 시작 |
| 결제 시스템·상용 선박데이터(Kpler류) | 수익화 단계에서 — **그 전에 유사투자자문 법률 확인 필수** |

즉 P0~P4까지는 사실상 추가 비용 0원으로 갑니다.

## 6. 전체 항해도 — 단계마다 당신이 할 일

| 단계 | 클로드 코드가 하는 일 | **당신이 하는 일** |
|---|---|---|
| P0 진수 | 저장소·이식·배포 | GitHub 가입, FRED 키 전달, 아이폰으로 검수 |
| P1 선체 | 실지형·모바일·PWA·가시성 1차 | 화면 보고 취향 피드백 |
| P2 혈액 | 데이터 배관, MOCK→실측 | aisstream 키 전달, "이 숫자 진짜야?" 검수 |
| P3 심판 | 검증 엔진, 피보나치 첫 판결문 | 판결문 문장 톤 검수 (당신이 편집장) |
| P4 극장 | 리플레이 확장(1997부터) | 시나리오 순서·내레이션 감수 |
| P5 승선권 | 회원·티어 | **법률 확인**, 가격 결정 |
| P6 운영 | 자동화·모니터링 | 블로그 연재 시작 |

## 7. 마음가짐 세 가지

1. **한 번에 하나씩.** 클로드 코드는 유능하지만, 좋은 선장은 "P0 끝나면 보고해" 식으로 단계를 끊어줍니다. 핸드오프 문서가 이미 그렇게 설계되어 있어요.
2. **화면이 진실이다.** 코드는 안 봐도 됩니다. 배포 주소를 열어 눈으로 검수하고, 마음에 안 들면 말로 고치세요.
3. **부수는 걸 두려워하지 마세요.** 깃이 모든 버전을 기억합니다. "되돌려줘" 한 마디면 어제로 돌아갑니다. 채팅에서 우리가 지구본을 네 번 갈아엎고도 매번 더 좋아졌던 것처럼요.
