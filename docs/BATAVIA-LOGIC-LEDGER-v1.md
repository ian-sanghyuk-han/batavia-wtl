# BATAVIA LOGIC LEDGER v1 — 로직 원장 전수판
> "무엇이 움직이면, 어느 시차로, 무엇이 어떻게 되고, 어떤 공식이 쓰였으며, 적중률이 어땠나" — 전체 목록.
> 표기 규약: 모든 P(적중률)·크기·시차는 **추정치**(문헌·역사 감각)이며 검증 엔진이 실측으로 교체한다. 행동 대신 **편향(상방/하방/우위)** 언어를 쓴다 — "언제 얼마나"는 기대값 부등식과 크기 규칙(F6·F7)이 답하고, 공개 규율과도 한 몸이기 때문이다.
> 카드 문법: `IF 트리거 → LAG 시차 → THEN 편향 · 공식 · SIZE 조건부(기저) · P±CI · n · WITH/UNLESS/DECAY` · 증거등급 A~F.

---

## F. 공식 라이브러리 — 카드들이 참조하는 수식

- **F1 서프라이즈** SDS = (발표 − 컨센서스) / σ(과거 서프라이즈) — 놀라움만 가격을 민다
- **F2 표준화** z = (x − μ창) / σ창 · 기본 창 60/120일, 포지셔닝 3년
- **F3 채권 감응** ΔP/P ≈ −D·Δy (듀레이션 근사)
- **F4 실질금리** r_real = 명목 − BEI · 금 ≈ r_real의 역함수
- **F5 캐리 기대** E[r] ≈ 금리차 − E[Δ환율] (UIP 위반이 수익의 원천, 급반전 꼬리 동반)
- **F6 기대값 부등식** EV = P·이득 − (1−P)·손실 − 비용 > 0 일 때만 카드가 "기회 후보"로 승격
- **F7 크기 규칙** f* = W − (1−W)/R (켈리) → 실무는 ½ 이하 · 폭풍(w↑) 시 추가 축소
- **F8 변동성** EWMA: σ²ₜ = λσ²ₜ₋₁ + (1−λ)r²ₜ, λ=0.94 · 군집: 큰 |r|은 큰 |r|을 부른다
- **F9 수렴도** C = 평균|ρᵢⱼ| (60일) · 0.38 긴장 / 0.55 경보
- **F10 허스트** R/S 기울기 H: >0.5 추세의 계절, <0.5 회귀의 계절
- **F11 사건 효과** CAR = Σ(rᵢ − 기대수익) 사건 창 누적 — 채점의 자
- **F12 국면 배율** 반응 크기 ≈ 기본 × (1 + 1.4w) · P' = P ± 게이트 보정(G1~G3)
- **F13 기본법칙** IR = IC × √BR — 얕은 엣지도 폭이 넓으면 강하다
- **F14 파이프라인** PPI·수입물가 → (1~3개월) → CPI 전가율 부분적

## 부록 — 원장의 운영 규칙
- 카드 수 현황: 1층 52 + 2층 12 + 게이트 3 = **67 등록**, 첫해 목표 80 (여백 13장은 실측 채점이 열어줄 신규 발견분).
- 상태 진급: 추정 → 사전등록(깃 해시) → 라이브 채점 → 실측 확정. 별도로 **관찰 보류(no-card)** 상태가 있다 — 엣지가 없다고 판단해 카드를 발행하지 않는 날도 한 줄로 기록되고 채점된다. 침묵도 성적의 일부다. 실측이 추정과 크게 다르면 카드는 강등되거나 기각 도장을 받는다 — 피보나치처럼.
- 모든 카드는 1:1로 대응한다: 블로그 한 편 · 레이더 후보 한 개 · 아카이브 채점 행 한 줄 · 책의 한 절.
- EV 부등식(F6)을 통과하지 못하는 카드는 "지식"으로 남고 "기회 후보"로 승격되지 않는다 — 아는 것과 쓸 수 있는 것의 구분.
